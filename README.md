# تی‌شرت استور - فروشگاه آنلاین تی‌شرت

سایت کامل فروشگاهی فقط برای فروش تی‌شرت، طراحی شده با HTML, CSS و JavaScript خالص.

## ویژگی‌ها

- ✅ صفحه اصلی با هیرو، ویژگی‌ها، محصولات ویژه و دسته‌بندی
- ✅ صفحه محصولات با فیلتر (دسته، سایز، رنگ، قیمت) و مرتب‌سازی
- ✅ صفحه جزئیات محصول با انتخاب سایز و رنگ و تعداد
- ✅ سبد خرید کامل (ذخیره در localStorage)
- ✅ صفحه درباره ما و تماس با ما
- ✅ طراحی ریسپانسیو (موبایل و دسکتاپ)
- ✅ زبان فارسی و راست‌چین کامل
- ✅ ۱۲ محصول نمونه آماده

## ساختار فایل‌ها

```
tshirt-store/
├── index.html          # صفحه اصلی
├── products.html       # لیست محصولات
├── product.html        # جزئیات محصول
├── about.html          # درباره ما
├── contact.html        # تماس با ما
├── css/
│   └── style.css       # استایل کامل
├── js/
│   ├── products-data.js  # داده‌های محصولات (اینجا محصولات رو ویرایش کن)
│   ├── cart.js           # مدیریت سبد خرید
│   ├── main.js           # صفحه اصلی
│   ├── products.js       # فیلتر و لیست محصولات
│   └── product-detail.js # جزئیات محصول
└── README.md
```

## چطور ویرایش کنی؟

### اضافه کردن محصول جدید
فایل `js/products-data.js` رو باز کن و یک آبجکت جدید به آرایه `products` اضافه کن:

```js
{
    id: 13,
    name: "نام تی‌شرت",
    category: "men", // یا women یا unisex
    price: 300000,
    oldPrice: 350000, // یا null
    colors: ["black", "white"],
    sizes: ["S", "M", "L", "XL"],
    badge: "جدید", // یا null
    description: "توضیحات محصول..."
}
```

### تغییر اطلاعات تماس و فوتر
در فایل‌های HTML بخش footer و contact رو پیدا کن و ویرایش کن.

### تغییر رنگ‌ها و ظاهر
فایل `css/style.css` رو باز کن و متغیرهای `:root` رو تغییر بده.

## چطور لینک واقعی داشته باشی؟ (رایگان)

### روش ۱: GitHub Pages (پیشنهادی)

1. یک حساب GitHub بساز (اگر نداری)
2. یک Repository جدید بساز به اسم مثلاً `tshirt-store`
3. تمام فایل‌های این پوشه رو آپلود کن
4. برو به Settings → Pages → Source رو روی `main` بذار
5. بعد از چند دقیقه لینکت آماده است:
   `https://YOUR-USERNAME.github.io/tshirt-store`

### روش ۲: Netlify (خیلی راحت)

1. برو به [netlify.com](https://www.netlify.com)
2. حساب بساز
3. پوشه `tshirt-store` رو بکش و رها کن (Drag & Drop)
4. لینک فوری می‌گیری!

### روش ۳: Vercel

مشابه Netlify، فقط فایل‌ها رو آپلود کن.

## پنل مدیریت محصولات

آدرس پنل: **admin.html**

- رمز عبور پیش‌فرض: `admin123`
- می‌توانید محصولات را اضافه، ویرایش و حذف کنید

- امکان تغییر رمز عبور

**نکته:** چون سایت استاتیک است، داده‌ها فقط در مرورگر همان دستگاه ذخیره می‌شوند.
